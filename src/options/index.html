AI Backend

Auto follows the priority chain: Chrome Prompt API (if available) → Gemini → Ollama → Built-in on-device AI. Manual selection overrides the chain.

Stored locally in browser.storage.local, encrypted at rest by the browser. Only sent to generativelanguage.googleapis.com.

Recommended: a sub-1B model like qwen3:0.6b or llama3.2:1b. Smaller models are faster but less accurate.

The model downloads from HuggingFace on first use and is cached locally in your browser (OPFS). No account, no key, nothing leaves your machine afterwards.

Currently using: Auto

Credibility Stamps

When enabled, badges appear next to video titles indicating whether the content is legitimate, exaggerated, misleading, etc.

User Interface

Shows a small bottom-right chip displaying model download progress and thumbnail swap status. Dismissible per session.

Animations

Title decode effect, thumbnail pixel-dissolve, and stamp pop-in. The system respects your OS `prefers-reduced-motion` setting.

Subtle reduces duration; full keeps all decorative flourishes intact.

Cache

Analyses are stored in IndexedDB. Negative entries (videos with no usable result) always expire after 24 hours regardless of this setting.

Channels

Allowlist

Channels exempt from rewriting/stamping — their original titles and thumbnails always shown. Enter channel name or URL and press Enter.

Blocklist

Channels whose videos are always aggressively flagged as potentially misleading. Same input method as allowlist.

Fact Check Layer

When enabled, Google Fact Check Tools API is queried for videos rated FAKE or covering news/health topics. Lookups race in parallel (400 ms timeout) and never delay the swap.
